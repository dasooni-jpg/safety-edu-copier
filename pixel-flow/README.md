# 픽셀 플로우 v2 — 색깔 가방 도트 퍼즐

`https://pixel.dasooni.workers.dev/` 에 올라가 있는 게임의 업그레이드 버전임.
보드 30×33(990칸) · 도안 31종 · 100단계라는 원래 뼈대와 난이도 설계는 그대로 두고,
플레이 편의·동기 부여·접근성을 보강함.

## 파일

| 파일 | 설명 |
|------|------|
| `index.html` | 게임 본체 (이 파일 하나만 있으면 실행됨) |
| `index.v1-backup.html` | 업그레이드 전 원본 (되돌릴 때 사용) |
| `pixel-flow-worker.template.js` | Cloudflare Worker 소스 템플릿 (`__APP_HTML__` 자리에 index.html이 끼워짐) |
| `pixel-flow-worker.js` | **배포용 완성본** — 이 파일을 워커 편집기에 붙여넣으면 됨 |
| `../build-pixel-flow-worker.ps1` | index.html을 고친 뒤 위 두 파일을 합쳐 worker.js를 다시 만드는 스크립트 |
| `tools/smoke-test.mjs` | 자동 점검 스크립트(선택) |

## 배포 방법

1. Cloudflare 대시보드 → Workers & Pages → **pixel** 워커 → Edit code
2. `pixel-flow/pixel-flow-worker.js` 파일을 열어 **전체 선택 → 복사 → 편집기에 덮어쓰기**
3. Deploy → `https://pixel.dasooni.workers.dev/` 새로고침

### 폴더째 올리고 싶을 때

파일 하나를 붙여넣는 대신 폴더를 통째로 올리는 방법은 `deploy/` 폴더에 준비해 둠.

- `deploy/pixel-worker/` — 지금 주소(`pixel.dasooni.workers.dev`)를 유지하는 방법. GitHub 연동 시
  Cloudflare 설정에서 **Root directory 를 `deploy/pixel-worker`** 로 지정하면 이후 푸시만으로 자동 배포됨.
- `deploy/pixel-pages/` — Cloudflare Pages 에 폴더(또는 zip)를 드래그해 올리는 가장 쉬운 방법. 주소는 새로 생김.

자세한 클릭 순서는 각 폴더의 `읽어보세요.txt` 와 `deploy/README.md` 에 있음.

화면만 고쳤을 때는 아래 순서로 다시 만들면 됨.

```powershell
powershell -ExecutionPolicy Bypass -File build-pixel-flow-worker.ps1
```

> 로컬에서 먼저 보고 싶으면 `pixel-flow/index.html`을 브라우저에서 그냥 더블클릭하면 됨.
> (서버가 필요 없는 단일 파일임)

## v2에서 새로 생긴 것

**게임성**
- **점수·콤보** — 가방을 낭비 없이 다 쓰면 `퍼펙트`가 뜨고 콤보 배수(최대 ×2.5)가 붙음. 단계별 최고 점수를 기록함.
- **되돌리기(↶)** — 방금 보낸 가방을 취소함. 판마다 3번. 연달아 보낸 가방은 함께 취소됨.
- **힌트(💡)** — 지금 손칸에서 가장 많이 지우는 가방을 알려 줌. 판마다 3번(연습 모드는 무제한).
- **연습 모드(🧪)** — 가방 개수 제한 없이 그림만 완성하는 모드. 기록에는 남지 않음. 실패 화면에서 바로 들어갈 수도 있음.
- **속도 조절(⏩)** — 빨아들이는 속도 1배·1.5배·2배.

**진행·수집**
- **도감(🎨)** — 완성한 도안을 31종 중 몇 종 모았는지 보여 주고, 눌러서 그림을 크게 볼 수 있음.
- **단계 목록 미리보기** — 100개 카드마다 도안 썸네일이 보임. 못 깬 단계는 실루엣으로 보임.
- **잠금 완화** — 앞 단계를 못 깨도 최고 기록 +3단계까지는 열림(막혀서 못 나가는 상황 방지).
- **최소 가방 기록** — 단계 카드에 그 단계를 몇 개로 깼는지 표시함.
- **이어하기** — 하던 판이 자동 저장됨. 앱을 껐다 켜도 그 자리에서 이어서 함.

**접근성·편의**
- **색 구분 기호(색약 배려)** — 색마다 ● ▲ ■ ◆ ✚ ★ 기호를 붙여 색만으로 구분하지 않아도 되게 함.
- **설정 화면(⚙)** — 효과음·진동·색 구분 기호·낭비 없는 가방 표시(쉬움)·속도를 한곳에서 켜고 끔.
- **키보드 조작** — `1~5` 손칸 가방 쓰기, `Q W E R` 더미에서 꺼내기, `Z` 되돌리기, `H` 힌트, `Esc` 뒤로.
- **가방 더미 3장까지 미리 보기**(원래 2장), 세로가 짧은 기기에서도 아래 줄이 잘리지 않도록 배치 조정.

**성능·안정**
- 보드를 **오프스크린 캔버스**에 그려 두고 바뀐 줄만 다시 그림 — 매 프레임 990칸을 새로 그리던 것을 없애 태블릿에서 부드러워짐.
- 단계 데이터 캐시, 창 크기 변경 디바운스 적용.
- 기존 v1의 별 기록(`pixelflow.progress.v1`)과 효과음 설정을 자동으로 이어받음.

## 저장되는 정보

서버에 저장하는 값은 없음. 진행 기록·설정은 **그 기기의 브라우저에만** 저장됨
(`pixelflow.progress.v2`, `pixelflow.opts.v1`, `pixelflow.resume.v1`).
이름·학번 등 개인정보는 입력받지도, 저장하지도 않음.

## 점검 방법 (선택)

Node와 Playwright가 있는 환경에서:

```bash
node pixel-flow/tools/smoke-test.mjs
```

홈 → 단계 선택 → 플레이 → 되돌리기 → 힌트 → 클리어 → 도감 → 이어하기까지 20개 항목을 자동으로 확인함.
