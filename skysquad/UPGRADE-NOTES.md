# 3차 업그레이드 — 세로 화면·기체 6종·지상 목표물·부품 보스·결과 화면 (2026-09-26)

## 1. 세로 화면 (1945식)
- 시작 화면 **"화면 방향"** 에서 **📱 세로 (1945식)** / **🖥 가로 (넓게)** 를 고름. 기본은 세로임. 기기에 저장됨
- 게임 규칙은 그대로 두고 **그리는 방향만 90° 돌림** → 서버를 바꿀 필요가 없고, 같은 방에서 학생마다 다른 방향으로 볼 수 있음
- 세로 모드에서 가로로 긴 모니터·태블릿은 양옆 여백에 점수판·편대원 카드를 둠
- 휴대폰은 세워서 쓰도록 안내함(눕히면 "세로로 돌려 주세요")
- 가로로 긴 태블릿에서 비행기가 작게 보이면 **가로 (넓게)** 를 고르면 됨

## 2. 기체 6종 (비행기마다 무기·차지샷·생김새가 다름)

| 비행기 | 무기 성격 | ⚡ 차지샷 | 생김새 |
|---|---|---|---|
| 하늘매 | 균형형 | 거대 포탄 1발 | 타원 날개 |
| 노을부채 | 넓게 퍼짐 (피해 약간 낮음) | 부채꼴 포탄 최대 9발 | 넓은 날개·기관총 4정 |
| 숲창 | 곧게 모이고 관통 | 한 줄로 뚫고 가는 창 | 긴 기수·뒤로 젖힌 날개 |
| 보라벌 | 빠른 연사 (한 발은 약함) | 적을 쫓는 유도 미사일 | 작고 날렵 |
| 분홍망치 | 사거리 짧고 강함 | 사방으로 퍼지는 충격파 | 쌍발 엔진 |
| 금빛독수리 | 보통 · **폭탄 +1** | 앞쪽 세로 한 줄 융단 폭격 | 날개 밑 폭탄 |

## 3. 지상 목표물과 금괴
- **전차·대공포·토치카·군함**이 땅과 함께 흘러오며 쏨. 부수면 **금괴**(250점~)를 떨어뜨림
- 지형 계산을 게임 규칙 파일로 옮겨 서버와 화면이 같은 땅을 봄 → **군함은 바다에, 전차는 땅에만** 나옴
- 부서진 자리에는 불탄 자국이 남아 땅과 함께 흘러감
- 성층권·우주에는 지상 목표물이 없음

## 4. 1945식 부품 보스
- 보스마다 **포탑 2~4개**(지역이 오를수록 늘어남). 포탑이 남아 있으면 본체는 **35%만** 맞음 (체력바가 회색, "포탑을 먼저 부수세요")
- 포탑을 부술 때마다 폭발 + 금괴. 모두 부수면 **"장갑 파괴!"** 와 함께 장갑 조각이 흩어지고 본체가 제대로 맞음
- 포탑은 가까운 조종사를 겨눠 두 발씩 쏨

## 5. 단계 결과 화면
- 클리어하면 **조종사별 격추·메달·금괴·얻은 점수** 표와 **단계 보너스·시간 보너스**가 숫자가 올라가며 나타남
- 시간 보너스: 목표 시간(웨이브 수 × 11초, 보스 단계는 +70초)보다 빨리 깰수록 커짐
- 결과를 읽을 수 있게 클리어 뒤 쉬는 시간을 4.6초 → 6.5초로 늘림

## 검증
- 자동 테스트 **187건 전부 통과** (기존 150 + 새 37: 기체 6종 12, 지형·지상 목표물 11, 부품 보스 9, 결과 5)
- 세로 휴대폰(390×844)에서 화면 위를 누르면 비행기가 앞으로 가는지 확인함
- 온라인 서버에서 분홍망치 차지샷(충격파 20발)이 나가는지, 2000틱이 오류 없이 도는지 확인함
- 초당 약 60프레임, 화면 오류 0건

## 배포 시 주의
게임 규칙 **버전이 3**이 됨. `skysquad-worker.js`를 반드시 다시 배포해야 함. 옛 화면을 열어 둔 기기는 새로고침하면 됨.

# 2차 업그레이드 — 1945 스타일 (2026-09-26)

'1945' 계열 비행 슈팅(스트라이커즈 1945, 1945 Air Force)의 핵심 요소를 이 게임에 맞게 옮김.
화면 방향(오른쪽으로 날아가는 가로 화면)은 그대로 둠. 세로로 바꾸면 100단계 설계와 온라인 서버를 모두 다시 만들어야 해서임.

## 게임 규칙 (sim.js — 서버도 같이 바뀜, 버전 1 → 2)

| 1945 요소 | 이 게임에서 | 세부 |
|---|---|---|
| 보조기(헬퍼 비행기) | 무기 Lv2부터 한 대씩, 최대 4대 | 내 비행기 위아래에서 따라오며 기관총을 쏨. 격추되면 무기 레벨과 함께 한 대 줄어듦 |
| 차지샷 | 게이지가 저절로 참 (한 칸 2.2초, 최대 3칸) | **X 키(또는 Z·Shift·Enter)** 나 **⚡ 버튼**. 모든 적과 방패를 뚫고, 보스에게는 두 배 피해 |
| 금메달 연쇄 | 6초 안에 이어 먹으면 값이 오름 | 100 → 200 → 300 → 500 → 800 → 1000 → 1500 → 2000. 보스를 잡으면 메달 10개가 쏟아짐 |
| 튕기는 P 아이템 | 화면 위아래 벽에 부딪혀 튕겨 다님 | 쫓아가서 먹는 재미. 가까이 가면 기존처럼 끌려옴 |
| 지원 폭격 | 💣 폭탄을 쓰면 폭격기 5대가 화면을 가로지르며 폭탄을 쏟음 | 피해 규칙은 기존과 같음(연출만 추가) |

## 화면

- **위에서 내려다본 전장**: 섬과 바다(배가 물살을 끌며 지나감), 붉은 협곡과 강, 밤의 도시 불빛, 설원과 호수·침엽수림, 사막과 오아시스, 용암이 흐르는 화산 지대, 빙하가 떠 있는 바다, 구름바다. 우주 관문은 별과 성운 그대로임
- **그림자**: 모든 비행기 그림자가 땅에 떨어져 높이감이 생김. 구름도 땅에 그림자를 드리우고, 일부 구름은 비행기 위를 지나감
- **2차대전식 프로펠러기**: 내 비행기(날개 표식·기관총·도는 프로펠러)와 적 전투기·쌍발 폭격기·4발 중폭격기·쌍동체기·급강하 폭격기를 새로 그림. 적 표식은 실제 나라 표식이 아닌 주황 테두리의 검은 마름모로 함
- **아이템**: 빨강·파랑으로 깜빡이는 P 캡슐, 빙글빙글 도는 금메달, B(폭탄) 캡슐
- **HUD**: 비행기 둘레 차지 게이지 3칸(가득 차면 깜빡임), 점수판 아래 메달 연쇄 표시, ⚡ 버튼
- **보스**: 형태가 바뀔 때 장갑 조각이 떨어져 나가며 '형태 변화!' 표시

## 검증

- 자동 테스트 **150건 전부 통과** (기존 134건 + 새 규칙 16건)
- 온라인 서버가 ⚡ 입력을 받아 차지탄을 쏘는 것을 확인함
- 모든 지역·보스 화면, 휴대폰 가로 화면(780×360)에서 오류 0건, 초당 약 60프레임

## 배포 시 주의

게임 규칙이 바뀌어 **버전이 2가 됨**. 반드시 `skysquad-worker.js`를 다시 배포해야 함.
배포 전의 옛 화면을 열어 둔 학생 기기에는 "버전이 다릅니다. 새로고침해 주세요." 안내가 뜸 → 새로고침하면 해결됨.

# 하늘편대 100 — 그래픽·기능 업그레이드 (2026-09-26)

바뀐 파일은 **`skysquad-app/index.html` 하나**와, 그것을 다시 묶은 **`skysquad-worker.js`**임.
게임 규칙 파일(`sim.js`)과 서버 틀(`skysquad-worker.template.js`)은 그대로임.
그래서 기존 방 코드·진행 기록·서버 방식이 모두 그대로 이어짐.

## 1. 고친 버그

| 증상 | 원인 | 결과 |
|---|---|---|
| 비행기·적 그림이 잘려 보임 (꼬리·왼쪽 날개, 폭격기 절반, 포대 일부) | 그림판 원점이 가운데가 아니라 1/4 지점에 있었음 | 모든 그림이 온전히 보이고, 보이는 위치와 맞는 위치가 일치함 |
| 적 엔진 불꽃이 몸통에서 떨어져 보임 | 적이 어느 방향을 보든 불꽃을 항상 오른쪽에 그렸음 | 꼬리 방향에 정확히 붙음 |
| 마우스로 할 때 커서가 안 보임 | 커서를 숨기고 대신 표시가 없었음 | 내 비행기가 향하는 곳에 노란 조준점이 보임 |
| 100단계에서 웨이브 점이 "100 단계" 글자와 겹침 | 점 위치가 고정값이었음 | 글자 폭에 맞춰 자리를 잡음 |

## 2. 그래픽

- **지역별 풍경 10종**: 산맥·구름 바다·계단 협곡·불 켜진 도시·눈 덮인 봉우리·사막 모래언덕·불 뿜는 화산·빙산·둥근 지구·고리 행성
- **하늘의 해·달·행성**: 새벽 햇살 기둥, 노을 해, 달, 붉은 해, 우주 행성
- **지역 날씨**: 속도선, 모래바람, 떠오르는 불씨(화산), 눈송이(빙하·오로라), 별 흐름(우주)
- **지역이 바뀔 때**: 구름을 뚫고 나오듯 하얗게 걷히는 연출 + 효과음
- **폭발**: 번쩍임 → 불덩이 → 불꽃 줄기 → 파편 → 부드러운 연기 → 충격파
- **내 비행기**: 두 줄기 엔진 불꽃, 위아래로 움직이면 날개가 기울어짐, 쏠 때 총구 불꽃
- **적**: 많이 다치면 연기를 뿜음, 포대·기뢰는 심지가 빛남
- **적 총알**: 흰 테두리를 둘러 피해야 할 것이 더 잘 보임
- **보스**: 지역 색 후광, 둥실 떠 있는 움직임, 체력이 줄면 불꽃·연기, 등장할 때 위아래 검은 띠(영화 느낌), 격파 때 마지막 큰 폭발
- **보스 체력바**: 깎인 만큼 흰 띠가 잠깐 남음, 형태가 바뀌는 지점 표시(▼), 남은 % 표시
- **글자 연출**: 단계·클리어·보스 배너가 튀어나오며 커졌다 제자리, 아이템을 먹으면 이름이 떠오름("무기 강화", "POWER UP")
- **점수**: 숫자가 올라가며 굴러감
- **시작 화면**: 뒤에서 편대가 날아가고 지역 풍경이 20초마다 바뀜, 버튼 반짝임

## 3. 새 기능

| 버튼 | 기능 | 비고 |
|---|---|---|
| ⏸ | 잠깐 멈춤 (키보드 **P**) | 혼자 연습에서만 보임. 온라인은 친구들이 같이 날고 있어서 멈추지 않음 |
| 🎵 | 배경음악 켜기/끄기 | 파일 없이 합성함. 지역마다 조가 바뀌고 보스전은 빨라짐. 효과음(🔊)과 따로 움직임 |
| ✨ | 그래픽 품질 높음/낮음 | 오래된 태블릿에서 4초 넘게 버벅이면 저절로 '낮음'으로 바뀜 |

설정(음악·그래픽)은 기기에 저장되어 다음에도 유지됨.

## 4. 검증 결과

- 자동 테스트(`_test.html`) **134건 전부 통과** — 게임 규칙이 바뀌지 않았음을 확인함
- 1·10·21·35·45·50·55·61·70·75·85·95·100단계 화면을 직접 띄워 확인함 (오류 0건)
- 휴대폰 가로 크기(780×360)에서 버튼 배치·일시정지·폭탄 확인함
- 크롬 기준 초당 약 50~60프레임
- 새 `skysquad-worker.js` 가 내보내는 화면이 새 `index.html` 과 글자 하나까지 같음을 확인함
