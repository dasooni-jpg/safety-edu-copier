# 하늘편대 100 — 그래픽·기능 업그레이드 (2026-09-26)

바뀐 파일은 **`skysquad-app/index.html` 하나**와, 그것을 다시 묶은 **`skysquad-worker.js`**임.
게임 규칙 파일(`sim.js`)과 서버 틀(`skysquad-worker.template.js`)은 그대로임.
그래서 기존 방 코드·진행 기록·서버 방식이 모두 그대로 이어짐.

## 1. 고친 버그

| 증상 | 원인 | 결과 |
|---|---|---|
| 비행기·적 그림이 잘려 보임 (꼬리·왼쪽 날개, 폭격기 절반, 포대 일부) | 그림판 원점이 가운데가 아니라 1/4 지점에 있었음 | 모든 그림이 온전히 보이고, 보이는 위치와 맞는 위치가 일치함 |
| 적 엔진 불꽃이 몸통에서 떨어져 보임 | 적이 어느 방향을 보든 불꽃을 항상 오른쪽에 그렸음 | 꼬리 방향에 정확히 붙음 |
| 마우스로 할 때 커서가 안 보임 | 커서를 숨기고 대신 표시가 없었음 | 내 비행기가 향하는 곳에 노란 조준점이 보임 |
| 100단계에서 웨이브 점이 "100 단계" 글자와 겹침 | 점 위치가 고정값이었음 | 글자 폭에 맞춰 자리를 잡음 |

## 2. 그래픽

- **지역별 풍경 10종**: 산맥·구름 바다·계단 협곡·불 켜진 도시·눈 덮인 봉우리·사막 모래언덕·불 뿜는 화산·빙산·둥근 지구·고리 행성
- **하늘의 해·달·행성**: 새벽 햇살 기둥, 노을 해, 달, 붉은 해, 우주 행성
- **지역 날씨**: 속도선, 모래바람, 떠오르는 불씨(화산), 눈송이(빙하·오로라), 별 흐름(우주)
- **지역이 바뀔 때**: 구름을 뚫고 나오듯 하얗게 걷히는 연출 + 효과음
- **폭발**: 번쩍임 → 불덩이 → 불꽃 줄기 → 파편 → 부드러운 연기 → 충격파
- **내 비행기**: 두 줄기 엔진 불꽃, 위아래로 움직이면 날개가 기울어짐, 쏠 때 총구 불꽃
- **적**: 많이 다치면 연기를 뿜음, 포대·기뢰는 심지가 빛남
- **적 총알**: 흰 테두리를 둘러 피해야 할 것이 더 잘 보임
- **보스**: 지역 색 후광, 둥실 떠 있는 움직임, 체력이 줄면 불꽃·연기, 등장할 때 위아래 검은 띠(영화 느낌), 격파 때 마지막 큰 폭발
- **보스 체력바**: 깎인 만큼 흰 띠가 잠깐 남음, 형태가 바뀌는 지점 표시(▼), 남은 % 표시
- **글자 연출**: 단계·클리어·보스 배너가 튀어나오며 커졌다 제자리, 아이템을 먹으면 이름이 떠오름("무기 강화", "POWER UP")
- **점수**: 숫자가 올라가며 굴러감
- **시작 화면**: 뒤에서 편대가 날아가고 지역 풍경이 20초마다 바뀜, 버튼 반짝임

## 3. 새 기능

| 버튼 | 기능 | 비고 |
|---|---|---|
| ⏸ | 잠깐 멈춤 (키보드 **P**) | 혼자 연습에서만 보임. 온라인은 친구들이 같이 날고 있어서 멈추지 않음 |
| 🎵 | 배경음악 켜기/끄기 | 파일 없이 합성함. 지역마다 조가 바뀌고 보스전은 빨라짐. 효과음(🔊)과 따로 움직임 |
| ✨ | 그래픽 품질 높음/낮음 | 오래된 태블릿에서 4초 넘게 버벅이면 저절로 '낮음'으로 바뀜 |

설정(음악·그래픽)은 기기에 저장되어 다음에도 유지됨.
