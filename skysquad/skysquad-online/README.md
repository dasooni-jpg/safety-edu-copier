# 하늘편대 100 — 다같이 100단계

친구 **5명까지** 같은 하늘에 모여 **100단계**를 함께 깨는 협동 비행 슈팅입니다.
그림 파일은 하나도 쓰지 않고 전부 코드로 그립니다(캔버스 벡터 아트).

## 파일 구성

| 파일 | 하는 일 |
|---|---|
| `skysquad-app/sim.js` | **게임 계산기.** 적 등장·이동·충돌·보스·아이템. 화면도 네트워크도 모릅니다. |
| `skysquad-app/index.html` | 화면·조작·소리·네트워크. 그림은 전부 여기서 캔버스로 그립니다. |
| `skysquad-app/_test.html` | 자동 테스트 132건 (봇 3명이 실제로 단계를 깨는 것까지 검사) |
| `skysquad-worker.template.js` | 서버(Worker + Durable Object). **여기를 고칩니다.** |
| `skysquad-worker.js` | 빌드 결과물. **직접 고치지 마세요.** 배포용 파일입니다. |
| `build-skysquad-worker.ps1` | 위 셋을 합쳐 `skysquad-worker.js` 를 만듭니다 |
| `skysquad-server.ps1` | 로컬 정적 서버(포트 4260). 테스트·혼자 연습 확인용 |

`sim.js` **하나를 서버와 브라우저가 같이 씁니다.** 그래서 온라인이든 "혼자 연습"이든
규칙이 어긋날 일이 없고, 테스트도 진짜 게임 코드를 그대로 돌립니다.

## 배포

다른 앱들과 달리 **대시보드 붙여넣기로는 배포되지 않습니다.**
Durable Objects 는 바인딩과 마이그레이션을 업로드 시점에 선언해야 해서 wrangler 가 필요합니다.

```powershell
powershell -ExecutionPolicy Bypass -File build-skysquad-worker.ps1
```

```powershell
cd skysquad-online
npx wrangler login      # 처음 한 번만
npx wrangler deploy
```

나온 주소(예: `https://skysquad.dasooni.workers.dev`)를 열면 게임이 바로 나옵니다.
게임을 고친 뒤에는 **빌드 → 배포** 를 다시 하면 됩니다.

로컬에서 진짜 온라인까지 시험해 보려면:

```powershell
cd skysquad-online
npx wrangler dev --port 4261
```

## 수업에서 쓰는 법

1. 주소를 연다 → 이름을 쓰고 비행기 색을 고른다
2. 한 명이 **방 만들기** 를 눌러 나온 **4글자 코드**를 칠판에 적는다
3. 나머지는 **친구 방 들어가기** 에 그 코드를 넣는다 — 게임 중에도 언제든 들어올 수 있습니다
4. 마우스·손가락을 움직이면 비행기가 따라옵니다. **총은 자동**이라 버튼을 누를 필요가 없습니다
5. 스페이스(또는 오른쪽 아래 💣)로 폭탄

**방은 진행한 단계를 기억합니다.** 다음 시간에 같은 코드로 들어가면
그 방이 깬 단계까지 골라서 이어 할 수 있습니다(방을 만들 때 시작 단계 선택).

## 협동 규칙

- 친구가 격추되면 낙하산으로 내려옵니다. **가까이 날아가 2.2초만 버티면** 살아납니다(목숨 소모 없음).
- 아무도 안 오면 14초 뒤 목숨 하나를 쓰고 스스로 일어납니다.
- **다 같이 쓰러지면** 그 단계를 처음부터 다시 합니다(벌칙은 점수뿐 — 아이들이 막히지 않게).
- 사람이 많아지면 적의 **수와 체력이 같이 올라갑니다**. 다섯 명이라고 3초 만에 끝나지 않습니다.

## 100단계 구성

10개 지역 × 10단계, 각 지역의 마지막(10·20…100)이 **보스**입니다.

| 지역 | 이름 | 보스 |
|---|---|---|
| 1 | 새벽 하늘 | 구름 요새 |
| 2 | 구름 바다 | 벌집 모함 |
| 3 | 노을 협곡 | 노을 비행선 |
| 4 | 별밤 항로 | 밤의 박쥐폭격기 |
| 5 | 오로라 지대 | 오로라 수정체 |
| 6 | 모래 폭풍 | 모래 폭풍룡 |
| 7 | 화산재 하늘 | 화산 거인 |
| 8 | 빙하 상공 | 빙하 여왕 |
| 9 | 성층권 | 성층권 요격기 |
| 10 | 우주 관문 | 우주 모함 오리온 |

적은 13종(정찰기·벌·폭격기·저격기·자폭기·방패기·회전포탑·분열기·수리기·미사일기·레이저기·기뢰),
지역이 올라갈수록 새 적이 합류합니다. **같은 단계는 언제나 똑같이 나옵니다**(시드 고정) —
아이들이 패턴을 익혀 다시 도전할 수 있게 한 것입니다.

## 요금 — 꼭 알아두세요

Durable Object 는 **깨어 있는 시간만큼** 과금됩니다. 실시간 게임이라 최면(hibernation)을
쓸 수 없어서, 방이 살아 있는 동안 계속 시간이 흘러갑니다.

- 무료 한도: 하루 13,000 GB-초 → DO 하나(128MB)로 **하루 약 29시간**
- 그래서 **접속자가 0명이 되면 45초 뒤 방을 비우고 루프를 멈춥니다**(그때부터 과금 없음)
- 90초 동안 신호가 없는 접속은 끊습니다. 방 정원은 6명

한 반이 수업 시간에 방 몇 개를 쓰는 정도면 무료 한도 안에서 넉넉합니다.

## 대역폭

한 사람당 **초당 약 10~25KB**. 총알은 위치를 매 틱 보내지 않고
"새로 생김 / 사라짐"만 알리고, 각 화면이 태어난 틱을 기준으로 직선 운동을 스스로 굴립니다.
(휘어지는 유도탄만 매 틱 위치를 보냅니다.)

## 고칠 때

1. 규칙을 고치면 `skysquad-app/sim.js`, 화면을 고치면 `skysquad-app/index.html`
2. `skysquad-server.ps1` 을 켜고 `http://localhost:4260/_test.html` 이 **전부 통과**인지 확인
3. `build-skysquad-worker.ps1` → `npx wrangler deploy`

`skysquad-worker.js` 를 직접 고치면 다음 빌드 때 지워집니다.
